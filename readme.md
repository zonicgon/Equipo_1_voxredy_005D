# VoxReady
Plataforma web SaaS para el entrenamiento de voceros mediante entrevistas simuladas con IA y una retroalimentación al final de cada simulacion.

Estado: En desarrollo.

## Descripción

VoxReady busca ayudar a directivos, portavoces técnicos y otros representantes de organizaciones a cómo responder, evaluando su lenguaje verbal y no verbal.

La plataforma propone entrevistas simuladas y configuradas por los administradores de la empresa que contraten el producto mediante el uso de la inteligencia artificial para la practica correspondiente de cada vocero y su respectiva evaluación para que pueda observar su desempeño y que mejorar respectivamente.
